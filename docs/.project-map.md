## 完整流程与数据传递

Notebook 参数 → build_patches → Patch 字典 → build_cnot / Builder → Experiment → 噪声 Stim → 完整/分解 DEM → 距离和 MWPM 统计 → JSON/CSV/Stim/图表。
主流程在同一内核传递 Python 对象；绘图、TQEC、交付复核通过 subprocess 运行现有脚本并读写本次目录。

## 统一术语

| 术语 | 含义 | 代码对应 |
|---|---|---|
| patch | 一个阶段的码区域 | Patch |
| boundary | 有序数据中心路径，类型表示可终止错误串 | Boundary |
| gauge check | 可随机的局部规范测量 | Check.gauge |
| super-stabilizer | 同类 gauges 的乘积 | Patch.stabilizers |
| bare logical | 与所有 gauges 对易的逻辑代表 | Patch.logicals |
| dressed CSS 距离 | 允许 gauge 等价后的最小逻辑数据权重 | Patch.analyze_distances |
| 测量 selector | 选取测量记录的整数 bit mask | bits / output_records |
| Pauli frame | 由记录决定的输出 Pauli 校正 | output_frames |
| detector | 确定性 parity 相对理想参考的翻转 | DETECTOR |
| 完整 DEM | 保留整个机制/hyperedge 的错误模型 | decompose_errors=False |
| 分解 DEM | 提供图匹配的错误模型 | decompose_errors=True |
